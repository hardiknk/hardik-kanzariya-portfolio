- Freelance backend and Laravel projects

## Technology

The portfolio is built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Three.js.

## Local development

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

The production output is written to `dist/` and uses relative asset paths for GitHub Pages
compatibility.

## Profile configuration

Availability, work preference, target role, timezone, and professional profile links are read from
Vite environment variables. Copy `.env.example` to `.env` for local changes. The same variable names
can be added as GitHub Actions repository variables for hosted updates.

- `VITE_AVAILABILITY_STATUS`
- `VITE_WORK_PREFERENCE`
- `VITE_REMOTE_TIMEZONE`
- `VITE_TARGET_ROLE`
- `VITE_LINKEDIN_URL`
- `VITE_GITHUB_URL`
